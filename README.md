# 🪙 Рубль Разум — Telegram-бот по финансовой грамотности

Телеграм-бот для сообщества «Рубль Разум». Помогает следить за финансовыми показателями, участвовать в прогнозах ключевой ставки ЦБ РФ, получить бесплатный шаблон таблицы бюджета и приобрести гайд по финансовой грамотности.

---

## Функционал

- 💱 **Курсы валют** — основные фиатные валюты (данные ЦБ РФ) и криптовалюты (BTC, ETH)
- 🔑 **Ключевая ставка ЦБ РФ** — актуальное значение из официального источника ЦБ
- 🎯 **Прогнозы по ключевой ставке** — перед заседанием ЦБ пользователи делают прогноз, после решения бот сравнивает его с фактической ставкой и присылает персональный результат
- 🔔 **Напоминания** — уведомления о ближайшем заседании ЦБ
- 📊 **Шаблон таблицы бюджета** — бесплатная таблица Google Sheets для ведения личного бюджета
- 📚 **Гайд по финансовой грамотности** — оплата через СБП, автоматическая доставка PDF после подтверждения платежа

---

## Как это работает

- **Курсы валют** запрашиваются у ЦБ РФ и CoinGecko, значения приводятся к рублям.
- **Ключевая ставка** берётся из официального сервиса ЦБ РФ и кэшируется, чтобы не нагружать источник.
- **Прогнозы**: окно приёма открывается незадолго до заседания и закрывается до объявления решения. Итоги рассылаются автоматически.
- **Оплата гайда**: бот создаёт платёж в ЮKassa, а после подтверждения оплаты автоматически отправляет файл в чат.

## Стек технологий

| Категория | Технология |
|-----------|-----------|
| Язык | Python 3.11+ |
| Telegram-фреймворк | aiogram 3.x |

## Структура проекта

```
handlers/    — обработчики команд и кнопок
services/    — бизнес-логика (курсы, ставка, прогнозы, платежи, файлы)
models/      — модели базы данных
keyboards/   — клавиатуры
states/      — FSM-состояния
utils/       — вспомогательные функции
api/         — serverless-функции
files/       — PDF и изображения
```

---

## Локальный запуск

1. Скопировать `.env.example` в `.env` и заполнить значения
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить: `python main.py`

Локально бот работает через polling, Redis и webhook не требуются.
