1. Нажмите `/start` и пройдите короткую регистрацию (имя и email).

## 📖 Подробнее о функциях

### 💱 Курсы валют

Выберите валюту из списка, и бот покажет актуальный курс к рублю.

- **Фиатные валюты**: USD, EUR, CNY, AED, TRY, GBP, GEL, BYN, CHF. Данные берутся у Центрального банка РФ.
- **Криптовалюты**: Bitcoin и Ethereum, цена пересчитывается в рубли.

### 🔑 Ключевая ставка

Один тап, и вы видите:

- текущую ключевую ставку ЦБ РФ;
- дату ближайшего заседания;
- свой прогноз, если вы его уже сделали;
- кнопку «Сделать прогноз» или «Изменить прогноз», когда приём открыт.

### 🎯 Прогнозы по ключевой ставке

Игра для тех, кто следит за решениями ЦБ.

1. **Перед заседанием** открывается окно прогнозов.
2. Вы отправляете своё предположение в свободном формате: `21`, `21.5`, `21,5%`.
3. Прогноз можно **изменить** до закрытия окна.
4. **После заседания** бот сравнивает ответ с решением ЦБ и присылает персональный результат: угадали или нет, и сколько раз ваше мнение совпало с решением регулятора за год.

### 🔔 Напоминания

Бот не даст пропустить заседание: напомнит заранее, накануне и в день заседания. Тем, кто уже сделал прогноз, лишние напоминания не приходят.

### 📊 Шаблон таблицы бюджета

Бесплатная таблица Google Sheets, которую можно скопировать себе в один клик:

- **«Общее»**: доходы, расходы и накопления по месяцам, разбивка по категориям, сравнительный график за год;
- **«Транзакции»**: журнал всех операций с датой, типом, категорией, суммой и заметкой;
- **«Справочник»**: список категорий, который легко подстроить под себя.

Итоги и диаграммы обновляются автоматически, нужно только вносить операции.

### 📚 Гайд по финансовой грамотности

Практический PDF-гайд: от оценки текущего финансового положения и целей до вкладов, кредитов, облигаций, акций и бонусного раздела по криптовалютам.

- Оплата через **СБП** по ссылке из бота.
- После подтверждения платежа файл **приходит в чат автоматически**.
- Если гайд уже куплен, его можно получить повторно бесплатно.

## 🛠 Технологии

| Категория | Технология |
|-----------|-----------|
| Язык | Python 3.11+ |
| Telegram-фреймворк | aiogram 3 |

## 📁 Структура проекта

```
handlers/    обработчики команд и кнопок
services/    бизнес-логика: курсы, ставка, прогнозы, платежи, файлы
models/      модели базы данных
keyboards/   клавиатуры бота
states/      состояния диалогов
utils/       вспомогательные функции
api/         serverless-функции
files/       PDF и изображения
```

## 💻 Локальный запуск

```bash
cp .env.example .env      # заполнить значения
pip install -r requirements.txt
python main.py
```

Локально бот работает через polling, дополнительных сервисов (Redis, webhook) не требуется.
